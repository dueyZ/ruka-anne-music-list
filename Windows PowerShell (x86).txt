       * 以下のGitコマンドを順番に実行して、ファイルの変更をGitHubに反映させます。
           1. git add public/songs.csv
           2. git commit -m "docs: 曲リストを更新" （docs:
              はドキュメントやファイル更新の際によく使われる接頭辞です）
           3. git push

   3. 自動デプロイ
       * git push が完了すると、Cloudflare Pagesが自動的に変更を検知し、更新された songs.csv
         ファイルを本番環境に反映します。
       * 数分待ってからデプロイ先のURLにアクセスすると、新しい曲のリストが表示されます。

  要約すると、「`public/songs.csv` を更新して、その変更を `git push` するだけ」で自動的にサイトに反映されます。
